❌ Before: Vulnerable (String Concat)

Route: GET /api/products/search-vulnerable?q=' OR '1'='1

// SQL constructed via string concatenation:
SELECT * FROM products WHERE name LIKE '%' OR '1'='1%'

// Explanation:
- Attacker input: ' OR '1'='1
- The single quote breaks out of the SQL string literal.
- Condition '1'='1' is TRUE for every record.
